Color Breakdown
Base Colors
#16703D (Deep Green) → Primary brand color

Use for headers, navigation bar, and key brand elements.

Works well as the dominant background for hero sections or call‑to‑action buttons.

#083045 (Dark Blue/Teal) → Secondary brand color

Use for footer, secondary buttons, or background sections to create contrast with the green.

Good for text highlights on lighter backgrounds.

#8F602C (Earthy Brown/Gold) → Accent color

Use sparingly for highlights: links, icons, hover states, or section dividers.

Great for drawing attention without overwhelming the design.

Highlight & Accent Strategy
Highlight color: #8F602C (because it pops against both green and blue).

Accent color: Use lighter tints of #16703D or #083045 for subtle backgrounds, cards, or hover effects.

👉 Tip: Keep #16703D as the “identity anchor,” #083045 as the “supporting tone,” and #8F602C as the “attention grabber.”
